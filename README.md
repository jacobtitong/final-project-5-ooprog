# Cinema Booking System

A terminal-based Java program where guests, registered users and cinema staff browse movies, book seats, pay,
and manage the cinema. All data is saved in plain `.txt` files.

## How to run

1. Clone this repo and open the folder.
2. Open `Main.java` and press Run.

The `.txt` data files are created in the project's main folder the first time the program saves. They are not
uploaded to GitHub.
